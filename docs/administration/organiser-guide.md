# Administration

Sign in and open `/admin`. Enter your password again to start the separate admin session.

| Task | Guide |
|---|---|
| Configure a new board | [Setup checklist](first-steps.md) |
| Create forums and control access | [Forums](forums.md) |
| Set permissions and promotions | [Groups](groups.md) |
| Registration and member roles | [Members](manage-members.md) |
| Name, logo, colours and themes | [Appearance](appearance.md) |
| Announcements, navigation and email | [Communications](community-communications.md) |
| Reports, warnings and bans | [Moderation](moderation-guide.md) |
| Registration and posting limits | [Spam controls](antispam.md) |
| Search language and limits | [Search](search.md) |
| Ratings and thanks | [Reputation](reputation.md) |
| Events | [Calendar](calendar.md) |
| Awards and achievements | [Awards](awards-guide.md) |
| Paid memberships | [Dues](membership-guide.md) |

Calendar, Awards and Dues require installed plugins. Package installation, deployment, storage and recovery require an operator; see [Operations](../operations/operating.md).

After permission changes, test as a guest and an ordinary member. Administrator access can bypass restrictions.
