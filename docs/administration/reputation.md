# Reputation and thanks

Open `/admin/settings?group=reputation`.

| Setting | Effect |
|---|---|
| Reputation enabled | Shows ratings and totals; disabling preserves existing ratings |
| Allow negative ratings | Enables negative votes; off by default |
| Require a comment | Removes one-click Thanks |
| Posts required before rating | Default 5; 0 removes the requirement |

Ratings are −1, 0 or +1 without group multipliers. Comments accept up to 500 characters. Ratings can target a post or profile.

## Member controls

| Negative ratings | Comment required | Controls |
|---|---|---|
| Off | No | Thanks |
| Off | Yes | Rating form |
| On | No | Thanks and rating form |
| On | Yes | Rating form |

The member needs **Can give reputation**, sufficient posts and a remaining daily allowance. Self-ratings are blocked. [Group allowances](groups.md) combine using the highest value; zero is unlimited. The day resets at midnight UTC.

Members can withdraw their own ratings. Totals update automatically, including after account merges. Check promotion and achievement rules before changing reputation policy.
