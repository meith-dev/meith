# Send messages and manage contacts

Use private messages to contact other members when the community permits it. Open `/messages` after signing in.

## Send a message

1. Open the compose page and choose the intended recipients.
2. Write a subject and message.
3. Review the recipients before sending.
4. Open the conversation to confirm the sent message appears.

The board may restrict messaging by group, daily allowance, storage quota or recipient preferences. If a recipient's inbox is full, the send can be refused; check the displayed message before retrying.

Reply addresses the message's author. Review the recipient list when you intend to include other people.

## Understand limits

A daily send allowance and a stored-message quota are separate controls. Deleting stored messages does not reset the day's send allowance. One send counts once toward the allowance even when it has several recipients.

If you cannot message someone, ask the organisers whether a community restriction applies. Do not try to bypass another member's contact preferences.

## Manage contacts

Open `/usercp/contacts` to manage buddies and ignored members. Ignoring a member hides their post body where supported; it does not remove their posts from the discussion or delete shared history.

## Report a message

Use the report action when a message requires moderator attention. Reporting is the route by which staff can review a private message; staff do not receive general browsing access to everybody's inbox.

For links, mentions and formatting, see [Write and format posts](formatting.md).
