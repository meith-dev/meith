# Notifications

Sign in to manage subscriptions and delivery preferences.

| Task | Action |
|---|---|
| Follow a thread | Use its subscription control |
| Manage followed threads | Open `/subscriptions` |
| Automatically follow threads you post in | Set the option at `/usercp/options` |
| Read notifications | Open `/notifications` |
| Set email and digest delivery | Open `/notifications/preferences` |

Unread events may be grouped. Disabling email leaves on-site notifications available. Unfollowing or muting a thread does not delete posts.

## Browser notifications

If web push is enabled, opt in through the board and grant browser permission. Browser permission alone does not subscribe you. Change permission later through the browser's site settings. See [Web push](../operations/web-push.md) for device requirements.

## Stop or troubleshoot delivery

Review both subscriptions and notification preferences. Email unsubscribe links change the relevant preference; keep those links private.

Delayed community-wide email can indicate a scheduler or mail-service problem. Ask an administrator to check it. Password-reset mail uses a separate request path.
