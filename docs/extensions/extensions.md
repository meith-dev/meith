# Extension development

Use a theme to change presentation or a plugin to add behaviour. Both are installed in the board repository and compiled into its build.

| Task | Guide |
|---|---|
| Create a plugin | [First plugin](first-plugin.md) |
| Add hooks, pages, storage or UI | [Plugins](plugins.md) |
| Create a theme | [First theme](first-theme.md) |
| Replace slots or change tokens | [Themes](themes.md) |
| Add translations | [Translations](internationalisation.md) |
| Submit a package listing | [Marketplace](marketplace.md) |
| Install an existing extension | [Installation](../operations/installing.md) |

Use pnpm in the Meith source workspace. Standalone board examples use npm because the generated board requires its dependency layout and tooling; see [Package management](../operations/configuration.md#board-files).
